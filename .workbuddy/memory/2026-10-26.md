# 2026-10-26

## ForgeX 权限模式切换优化（apps/cli + packages/core）

用户反馈"切到 plan 模式后不知道怎么回 agent 模式"，排查后确认 ForgeX 只有 `/plan` 布尔开关，
且 `--mode` 在 `apps/cli/src/args.ts` 里声明为取值参数却无任何消费方（传了不生效）。已优化：

- 新增 `apps/cli/src/config/permission-mode.ts`：`PERMISSION_MODES` 循环顺序、别名解析
  （ro/std/trust/danger…）、`nextPermissionMode`、`permissionModeHelp`，纯函数可单测。
- `load-config.ts` 新增 `permissionMode` 选项，`--mode` 覆盖配置文件与环境变量，
  非法值抛 `CONFIG_INVALID` 并回显可选值；`sources` 增加「命令行参数（--mode）」。
- `packages/core/src/agent/agent.ts` 新增 `setPermissionMode()`：处于计划模式时先真正退出
  计划模式再落目标权限（避免 readonly 残留把新设置冲掉），并 emit notice。
- TUI（`ui/App.tsx`）：`Shift+Tab` 循环权限模式（计划模式下先退计划模式）、
  新增 `/mode [readonly|standard|trusted|yolo|plan|agent]`、状态栏 `⇧⇥` 提示、HELP/命令面板更新。
- 纯文本模式（`ui/plain.ts`）同步支持 `/mode`。
- `--plan` 布尔参数：`chat`/`run` 启动即进入计划模式，供 CI dry-run。
- `doctor` 增加「权限模式」检查项（yolo 告警）；`main.ts` 帮助与 README 更新。
- 测试：新增 `apps/cli/test/permission-mode.test.ts`(9)，扩充 args/config/core 用例；
  `pnpm typecheck` 通过，`pnpm test` 846 全绿；冒烟验证 `config --mode trust`、非法值报错、
  plain `/mode` 全链路、Ink 对 `\x1b[Z` 解析为 tab+shift。

关键事实：Ink 5 中 Shift+Tab = `\x1b[Z` → `key.tab && key.shift`；普通 Tab 的 shift 为 false。
